# Drew's confirmed schedule

Update this **every Sunday before 4am Central** so the Sunday marketing agent
can write **location-specific CTAs** ("Drew is in Granbury Thursday — DM to
book") instead of generic regional ones ("DFW area").

The agent only reads entries with a `## YYYY-MM-DD` date heading. Anything
without that prefix is ignored. Entries are picked up for the next 7 days from
the run date.

If you leave this file empty (or no upcoming entries), the agent falls back to
generic regional language. The "never invent locations" rule is still enforced
— the agent cannot name a city unless it appears below.

---

## Format examples

    ## 2026-05-20  Granbury, TX  (multiple barrels)
    ## 2026-05-21  Aubrey, TX
    ## 2026-05-22  DFW (open — booking up)
    ## 2026-05-24  Decatur, TX
