# Manual ad batch — curated ChatGPT-generated ads

Hand-picked from Charles's 2026-05-15 batch of 21 ChatGPT-generated ads. These
10 made the cut after evaluating against:

- Short Go brand voice (rural-luxury, rodeo-native, Tecovas / Yellowstone feel)
- The 2026-05-15 competitor scan (avoid clinical close-ups, anatomy diagrams,
  before/after gait comparisons, sunset-rider portraits, mom-and-daughter tropes,
  testimonial carousels — all of which the field is saturated with)

These are **finished ads** — text + brand mark are already burned in. Drop them
into IG/FB manually as you see fit. **Note**: the brand mark on these (galloping
horse silhouette + SG monogram + "EQUINE CHIRO") is different from the Sunday
auto-render's mark ("SHORT GO EQUINE CHIROPRACTIC" + state cue). Either rotate
deliberately, or eventually pick one and update the Sunday agent to match.
