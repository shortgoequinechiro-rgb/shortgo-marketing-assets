# Short Go — Photo Library

Drop ChatGPT-generated images here as you produce them.

## Naming convention

```
NNN-batch-shortname.png
```

- `NNN` matches the brief number in `../chatgpt-image-library-prompt.md`
- `shortname` is 2–4 words for human readability
- Variations: `NNN-shortname-v2.png`, `v3`, etc.

## Examples

```
001-arena-sunrise-empty.png
013-tx-pasture-sunrise.png
031-leather-texture.png
045-hoof-print-clay.png
049-hands-arena-sand.png
```

## How the agent uses these

The Short Go Marketing Agent will read this folder when composing each weekly post and pick the best-fit image based on the post's content category. Once an image has been posted, the agent logs it to `../content-log.md` under POSTED so it doesn't repeat the same image within 60 days.

## Categories at a glance

| Brief range | Category | Best for |
|---|---|---|
| 001–012 | Arena & barn interiors | Educational text-overlay posts (the workhorses) |
| 013–020 | TX/MT landscape | CTAs, seasonal posts, brand-mood hero shots |
| 021–030 | Tack, tools, objects | Quote cards, philosophy posts, BTS captions |
| 031–038 | Texture & color washes | Quote cards, stat cards where TEXT is the focal point |
| 039–044 | Mobile rig, truck, road | "We come to the barn" service-explainer posts |
| 045–050 | Symbolic wellness objects | Educational + philosophy posts |
